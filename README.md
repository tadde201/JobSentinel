# JobSentinel

JobSentinel is an AI-powered job monitoring and application tracking platform that monitors targeted companies, detects new opportunities, scores job matches, sends notifications, and tracks applications.

## Overview

This project helps job seekers stay on top of opportunities by keeping a watchlist of target companies and job boards, surfacing new roles quickly, and tracking each stage of the application process.

## Project structure

- backend/
- frontend/
- data_pipeline/
- database/
- tests/
- docs/

## Getting started

1. Copy `.env.example` to `.env` and fill in your configuration.
2. Set up the PostgreSQL database.
3. Install backend and frontend dependencies.
4. Start the application.
